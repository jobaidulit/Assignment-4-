    Event Bubbling is the process where an event starts on the target element and then propagates upward through its parent elements in the DOM.

    How its works

  • Event triggers on the child element
  • It move up to its parent
  • Continues up to document and window

    • Example

    Clicking a button inside a div -> button handler runs first -> then div handler -> then higher ancestors.

    Event Delegation is a technique where you attach a single event listener to a parent element instead of adding listeners to multiple child elements.

    It works because of event bubbling — the event bubbles up from the child to the parent.

    why it's usefull:

  • Improves performance
  • Works for dynamically added elements.
  • Cleaner, more maintainable code.
  • preventDefault() -> blocks default action.
  • stopPropagation() -> blocks event flow.
